# Ладно — локальный интерактивный прототип

Дата: 2 ноября 2026. Статус приёмки и доказательства этой версии фиксируются в [APP-003](../team/tasks/APP-003.md).

Пользователь выбрал продолжение без Figma. Прототип позволяет исследовать бюджет, операции, цели и долги в браузере. Это демонстрация поведения и дизайна, не готовое финансовое приложение.

## Открыть и попробовать

- [Работающий локальный просмотр](http://127.0.0.1:8766/).
- Исходная страница: [prototype/index.html](../prototype/index.html); HTML/CSS/classic JavaScript без установки пакетов и внешних библиотек.
- Из корня проекта можно запустить `python -m http.server 8766 --bind 127.0.0.1 --directory prototype`, затем открыть ссылку выше. Сервер отдаёт только папку прототипа и слушает только этот компьютер. В текущем окружении его запуск потребовал одобренного выхода из песочницы; браузер запрещает file://, поэтому прямое открытие файла в нём не проверялось.

Начните с четырёх разделов и фильтра «Переводы» в операциях: в D1 переводов нет, поэтому появится пустой результат со сбросом фильтра. В форме операции введите `1200,999`: ожидается ошибка точности с сохранённым вводом. После исправления на `1200,99` можно добавить демонстрационный расход и увидеть пересчёт бюджета. «Сбросить демо» возвращает исходный набор. Переключатель «Состояние экрана» отдельно показывает варианты пусто/загрузка/ошибка для обсуждения дизайна.

## Данные и границы

Все данные синтетические: D1, октябрь 2026, KZT, два знака после запятой; цели/долги на 30.10.2026. Исходные доходы 500 000,00, расходы 300 000,00, план 350 000,00 и остаток бюджета 50 000,00 KZT. Накопление 180 000,00 из 600 000,00 KZT; «Я должен» 80 000,00 и «Мне должны» 50 000,00 отдельно.

Начальный баланс счёта неизвестен: остаток бюджета и доход минус расход не подменяют баланс. Цели и долги ведутся отдельно и не создают скрытые операции. Для перевода нужны два разных счёта; в D1 только один, поэтому такой ввод блокируется с пояснением. Денежные вычисления используют целые минимальные единицы, без округления лишних дробных знаков.

Изменения существуют только в памяти текущей вкладки; обновление страницы или сброс возвращают D1. Нет долговременного хранения, банковских подключений, синхронизации, серверных расчётов и публикации. Сетевых запросов приложения к внешним сервисам нет; локальный HTTP нужен только для отдачи файлов браузеру. Будущая платформа продукта ещё не выбрана.

## Фактические проверки и воспроизведение

Выполнены Get-Content входов, rg с номерами строк, Get-FileHash и PowerShell-проверка: сравнение шести хэшей со снимком; четыре карты SC; наличие текстов формы/состояний; D1 count/type/opening/ledgerEffect. Команда завершилась exit 0.
Ожидалось: неизменные входы, четыре SC-карты, сохранённая ошибка суммы, неизвестное ≠ ноль; отдельные строки фильтра требуются контрактом. Факт: первые условия подтверждены, обе строки фильтра отсутствуют — UX2-01.
Минимальное воспроизведение обнаруженного пробела и предпосылок из корня проекта, PowerShell:

```powershell
$uxSource = Get-Content -LiteralPath 'design/figma-05-states-form.js' -Raw
$uxData = Get-Content -LiteralPath 'design/demo-data.json' -Raw | ConvertFrom-Json
$uxSource.Contains('По этим фильтрам ничего нет')
$uxSource.Contains('Сбросить фильтры')
$uxSource.Contains('1200,999')
$uxSource.Contains('Все введённые значения остаются в форме.')
$uxSource.Contains('Неизвестное и ошибка ≠ ноль.')
$uxData.operations.Count
@($uxData.operations | Where-Object type -eq 'transfer').Count
$null -eq $uxData.accounts[0].opening
```

Получено при проверке полного набора: `INPUT_HASHES=6/6 match frozen snapshot; MAPPINGS=4; FORM_MARKERS=present; UNKNOWN_NOT_ZERO=present`; `FILTER_EMPTY=False; FILTER_RESET=False`; `D1_OPERATIONS=4; D1_TRANSFERS=0; OPENING=null; GOAL_DEBT_LEDGER=none`.
Минимальная команда выше также выполнена отдельно: False, False, True, True, True, 4, 0, True; exit 0. Это статическая проверка текста/фикстуры, не исполнение Figma-скрипта и не тест приложения.

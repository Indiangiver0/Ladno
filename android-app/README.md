# Ладно — личные финансы для Android

Локальное приложение для доходов, расходов, категорий, распознавания чеков и учёта выбранных банковских уведомлений. Версия 0.2.0, package `com.ladno.finance`, Android 8.0+ (API26). APK для личной установки, подписанный прежним локальным ключом разработки. Обновление устанавливается поверх 0.1.0. Два телефона ведут отдельные базы: синхронизации и общего семейного счёта нет.

## Установка и первый запуск

1. APK обновления: `dist/ladno-0.2.0-debug.apk`. Для этого проекта ранее использована обычная установка разработки через USB/ADB. Интернет-установку может блокировать Play Защита из-за доступа к уведомлениям; отключение защиты не требуется для сборки и не является частью проекта.
2. Откройте «Ладно». Выберите основную валюту и часовой пояс, подтвердите правило даты уведомлений. Новая установка не содержит демонстрационных операций.
3. В «Операциях» добавляйте доходы и расходы. Есть 15 стартовых категорий; свою можно создать прямо в форме. Месяц и валюта выбираются над итогами. «Графики» показывает расходы по категориям за выбранный месяц в одной валюте; «Без категории» также учитывается.
4. В «Разборе» выберите камеру или изображение чека. Снимайте весь текст с итогом и датой. OCR работает на телефоне с русской, казахской и английской моделями; отдельного чтения QR нет. Реквизиты сверяются двумя локальными моделями: расхождение требует проверки, даже при высокой оценке уверенности OCR. После обработки виден результат: добавлен расход, нужна проверка либо повтор. Если итог, валюта, дата или успешная оплата не определены однозначно, проверьте поля перед проведением. Неучтённый скан можно убрать из разбора без создания расхода.
5. В «Настройках» выберите приложения банков и сохраните источники. Кнопка доступа откроет системные настройки Android; доступ к уведомлениям включаете вы. После этого обрабатываются новые уведомления выбранных приложений.

Явное распознанное сообщение о завершённой операции может создать запись без категории. Повторы и возможные совпадения с чеком отправляются на разбор. Если операция уже внесена, выберите связь с существующей записью. «Игнорировать» исключает материал из учёта. Ошибочную операцию можно исправить вручную.

## Границы версии

- Выбор источника доступен для установленных приложений с launcher-экраном. Это не подключение к банковскому API. Проверенного списка всех банков пока нет: неизвестные форматы требуют разбора, скрытые суммы не восстанавливаются.
- Приложение не читает старые SMS, историю уведомлений и счёт в банке. Android или банк могут скрывать текст; запреты рабочего профиля и ограничения устройства могут мешать доставке уведомлений.
- Читаются только выбранные источники после выдачи системного доступа. Пароли и полные исходные тексты уведомлений не сохраняются в журнале приложения. Доступ можно отключить в настройках Android.
- Данные хранятся локально; у приложения нет разрешения на интернет. Камера запускается через системное приложение, галерея — через системный выбор файла. Проверяйте нечёткие чеки и предложенные совпадения.
- Экспорта, синхронизации и восстановления удалённого приложения пока нет. Удаление приложения или потеря телефона может привести к потере учёта. Ключ разработки нужен для установки будущего обновления поверх этой версии; не удаляйте его из локального кэша сборки.
- Фактически выполненные проверки и ограничения проверки на устройстве фиксируются отдельно в `dist/` и `team/reports/APP-005-*`. Просмотр интерфейса в браузере использует отдельную пустую базу в памяти и не доказывает работу Android-сервисов.

## Сборка на Windows

Из корня репозитория:

```powershell
python -u android-app/scripts/build_android.py --tools-root C:\Users\04068\.cache\ladno-android --accept-sdk-license
```

Флаг `--accept-sdk-license` нужен только для первоначальной установки выбранных пакетов SDK после прочтения официальных условий Android SDK. Скрипт скачивает проверенные инструменты в отдельный кэш, не меняет системный PATH, копирует исходники в путь ASCII и выполняет `assembleDebug`, `testDebugUnitTest`, `lintDebug`. Повторная сборка с установленным SDK не требует флага принятия условий.

Результат: `dist/ladno-0.2.0-debug.apk`, `build-result.json` с SHA-256/отпечатком исходников, журнал Gradle, отчёты тестов и lint. Версии инструментов закреплены в `build-versions.json`, модели FAST — в `ocr-models.lock.json`, BEST — в `ocr-verification-model.lock.json`. Обе группы моделей включены в APK; загрузки чеков или моделей из приложения нет. Денежный контракт и граница native/UI описаны в `docs/android/` корня репозитория.

# APP-005 — ответ адвоката реализации после раскрытия

Задача и версия: один раунд по C005-01 и USR-01/02/03; android-alpha-v1,108 файлов, digest `87b8a045ac6e104e802cca11e6bbae40cceb5d688e13e681e654a990f4f99864`, APK `38c9d4490419eda3685e7187281d5f1ecfb958a95d77c57f7f59633febcfbd5a`.
Выполненное: прочитаны все три [initial критика](APP-005-critic.md), [реализации](APP-005-implementation.md), [пользователя](APP-005-user.md). Новые runtime/QA проверки не запускал, продукт и замороженные108 файлов не менял; оснований для повторения прежних сверок нет.

## Ответы по ID

- **C005-01 / P2 / признаю подтверждённый пробел доказательств.** Согласен с критиком: A2–A5 остаются частичными, открытый пункт блокирует полную приёмку. Наличие настоящих SQLite/NLS/Tesseract и успешная сборка защищают выбор реализации, но не доказывают работоспособность её Android-переходов. Источник: [QA матрица](../reports/APP-005-qa-review.md). Действие: независимый Android-проход по перечисленным критиком сценариям с ожиданиями и фактами по этой версии. Ошибка продукта этим пунктом не установлена.
- **USR-01 / P2 / признаю.** Пользователь не должен считать APK проверенным постоянным учётом. Browser CRUD и host reopen не проверяют Android bridge→LedgerStore→restart; parser/JNI упаковка не проверяет OCR/NLS→запись. Возражений к необходимым сценариям и проверке точных сумм/валют/дат нет. Источники: [scenario limits](../../android-app/qa/scenario/REPORT.md), [calculation limits](../../android-app/qa/calculation/REPORT.md). Действие совпадает с C005-01; это один существенный пробел, а не несколько доказанных отказов.
- **USR-02 / P2 / признаю ограничение покрытия.** Желаемые «все банки» остаются исходной целью. Общий conservative parser, allowlist и маршрутизация review обоснованы как начальная реализация; они не закрывают универсальную поддержку. Источники: [PERSONAL-MVP U5/R5](../../docs/product/PERSONAL-MVP.md), [README](../../android-app/README.md). Действие: проверить размеченные обезличенные форматы и Android-доставку, указывать фактическую область, сохранять непроверенное открытым. Передача личных сообщений пользователя не нужна для выдачи самой альфы.
- **USR-03 / P2 / признаю неоднозначность передачи; устранение предложено, ещё не выполнено финальным сообщением.** Фраза README «OCR работает на телефоне» описывает реализованный путь сильнее доказанной области. Для ограниченной передачи этой версии достаточно прямой оговорки рядом со ссылкой APK в финальном сообщении начальника: A6 требует явного сообщения ограничений; отдельного требования менять README до передачи альфы нет. Предложение адвоката пользователя принимаю без изменения frozen108. Это устраняет только неоднозначность передачи, не пробелы USR-01/02.

## Конкретная оговорка для передачи

«Собран подписанный debug APK 0.1.0 для личной установки и проверки. Установка и запуск на Android, сохранение записей между перезапусками, камера/распознавание чеков и реальные банковские уведомления ещё не проверялись на Android. Поддержка всех банков не подтверждена. Экспорта и восстановления нет; на двух телефонах отдельные локальные базы без синхронизации. Это альфа; полная функциональная приёмка ещё не выполнена».
Рядом нужны ссылки на сам APK и [руководство](../../android-app/README.md). Отсутствие синхронизации/экспорта сообщается как фактическая граница, обязательным новым критерием его не объявляю.
Если потребуется изменить встроенные тексты/README, это отдельная авторская правка с новой фиксацией затронутой версии; для предложенной оговорки при передаче такой product fix не требуется.

## Оставшиеся вопросы и рекомендация судье

Существенных разногласий с критиком и адвокатом пользователя по открытым пробелам нет; спор ради опровержения согласованных фактов не создаю. Мои IA005-01/02/03 сохраняются: native execution, банковское покрытие и практическая пригодность strict paid-marker требуют своих доказательств.
Рекомендую **insufficient_evidence для полной приёмки APP-005**. Отдельная передача проверенного файла APK как debug-альфы допустима с приведённой оговоркой, без статуса accepted исходной задачи и без объявления A2–A5 закрытыми. Судья решает по всему пакету; это ответ стороны, не вердикт.

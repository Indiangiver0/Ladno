# APP-005 — ответ адвоката пользователя после раскрытия

Задача/версия: тот же `android-alpha-v1`, 108 файлов, digest `87b8a045ac6e104e802cca11e6bbae40cceb5d688e13e681e654a990f4f99864`; APK `38c9d4490419eda3685e7187281d5f1ecfb958a95d77c57f7f59633febcfbd5a`. Автором продукта не являюсь.
Выполненное: `Get-Content` всех трёх раскрытых initial; ожидание — ответить на конкретные доводы, факт — позиции по полной приёмке и допустимости альфы согласуются. Новых тестов/аудита не проводил, frozen-продукт не менял.

## Ответы сторонам

- **C005-01 / P2 / признаю подтверждённый пробел доказательств.** Согласен с критиком: A2–A5 не закрываются сборкой, browser preview или host SQLite. Это совпадает с USR-01; не считаю совпадающие пункты разными дефектами. Конкретные Android-проходы критика достаточны как следующий этап; личные данные пользователя для них не обязательны. Доказательство: [critic](APP-005-critic.md), [матрица QA](../reports/APP-005-qa-review.md).
- **IA005-01 / P2 / признаю.** APK, native-код и частичные проверки реальны, их ценность не отрицаю. 24 JUnit/211 JVM/39 host SQLite/17 browser groups/55 APK checks относятся к названным областям; обязательные persistence/OCR/NLS/ingest-сценарии Android остаются неисполненными. Подтверждённого отказа или ошибочного денежного результата этим не установлено. [Implementation](APP-005-implementation.md) не пытается заменить полную цель передачей файла.
- **IA005-02 / P2 / признаю ограничение покрытия.** Соответствует USR-02. «Все банки» сохраняется открытой целью, а передача альфы не означает её отмены. Матрица проверенных форматов и Android-доставки нужна для честных последующих обещаний; неизвестный формат не может считаться проверенным автопостом. Универсальную несовместимость также не утверждаю.
- **IA005-03 / P2 / признаю ограничение; масштаб не доказан.** Требование paid marker защищает от ложного расхода, что подтверждает исправленный QA-CALC01. Но обязательный ясный автопост R4 нельзя незаметно заменить ручным вводом для всех чеков. Нужен размеченный корпус оплаченных/неоплаченных RU/KZ/EN изображений через настоящий OCR; по текущим доказательствам нельзя утверждать ни массовый отказ реальных чеков, ни их достаточное покрытие. Основание: [implementation](APP-005-implementation.md), [AC-03/04](../../docs/product/AUTO-ENTRY-ACCEPTANCE.md). Смягчать parser без отрицательных регрессий не предлагаю.

## USR-03 и конкретная передача

**USR-03 / P2 / уточнение:** это условие понятной будущей передачи, а не уже совершённая вводящая в заблуждение передача. Handoff ещё не отправлен. Достаточно прямого сообщения ниже рядом с APK и [руководством](../../android-app/README.md); изменения frozen108 не требую. Закрытие условия фиксируется по фактически отправленному тексту.

> Собран debug APK «Ладно» 0.1.0 для личной установки на Android 8+. Это альфа для проверки: её ещё не устанавливали и не запускали на Android; сохранение после перезапуска, камера/OCR и реальные банковские уведомления на устройстве пока не проверены. Поддержка всех банков не подтверждена. Данные двух телефонов раздельны; экспорта и восстановления нет — при удалении приложения или потере телефона записи могут быть утрачены.

README и первый экран уже показывают материальный риск локальных данных. Экспорт/синхронизация/общий семейный бюджет пользователем не требовались; не делаю их новыми условиями допуска альфы или полной приёмки нынешнего объёма. Риск должен оставаться видимым в передаче, особенно перед использованием для единственного экземпляра учёта.

## Рекомендация судье и оставшиеся вопросы

Полная цель A2–A5 остаётся обязательной и доказана лишь частично: рекомендация `insufficient_evidence` сохраняется по единому пробелу C005-01/IA005-01/USR-01 и неподтверждённому охвату IA005-02/USR-02. Подтверждённых открытых P0/P1 не заявляю. Для отдельной передачи артефакта допустима честно обозначенная альфа с приведённым handoff; это не `accepted` всей задачи. Открыты устройство и корпус форматов; далее независимый Android-проход и решение отдельного судьи. Между раскрытыми позициями предметного противоречия не обнаружил.

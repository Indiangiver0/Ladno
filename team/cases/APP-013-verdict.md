# APP-013/014 — независимый вердикт

**Задача и версия.** Судья `/root/qr_court_judge` не участвовал в реализации или защите. Рассмотрена 0.3.0/code3: [APK](../../android-app/dist/ladno-0.3.0-debug.apk), SHA256 `a8ec70cd97674fb6f9c8d224e10139611c52a4ac25f69f6cd26143f7d88e5b76`; [snapshot v4](../snapshots/android-alpha-v4.json), 140 файлов, manifestSHA `9e992a831fa5be3a758c71c51529638fb5be37728631258ee6a0f17faa51f7ce`.

**Выполненное.** Прочитаны правила, [общий пакет с телефонным дополнением](APP-013.md), контракт, QA и все шесть позиций: [критик initial](APP-013-critic-initial.md)/[response](APP-013-critic-response.md), [реализация initial](APP-013-implementation-initial.md)/[response](APP-013-implementation-response.md), [пользователь initial](APP-013-user-initial.md)/[response](APP-013-user-response.md). Независимость первоначальных позиций и последующий обмен зафиксированы начальником. Решение основано на доказательствах, не голосовании.

**Доказательства.** Собственная read-only команда PowerShell `@'…'@ | python -` с `hashlib/json/ElementTree`: ожидание — совпадение frozen bytes/manifest/APK; факт — 140 совпадений, 0 расхождений, оба SHA совпали. Агрегация сохранённых [JUnit XML](../../android-app/dist/test-results/testDebugUnitTest/) дала 80 listed/79 pass/0 fail/1 skip; [native evidence](../../android-app/qa/app013/native-runtime-evidence.json) — 82/82, [artifact identity](../../android-app/qa/app013/artifact-identity.json) — 108/108. Это чтение результатов, не повторный запуск тестов. По [QA](../reports/APP-013-qa-review.md) Gradle/AVD запускал chief, независимый специалист подготовил проверки, глава их проверил. Synthetic PNG→decoder→runtime→SQLite подтвердил 1234.50 KZT, scale2 без округления, дату 2026-11-04, review/неизвестный вид, отсутствие ledger-записи и сохранение ignore. Reflection-регистрация внутреннего Job не проверяет Activity/камеру/банковский callback. Новых field tests судья не выполнял.

**Решения по существенным ID.**

1. **API13-01/QA13-03/CR13-01/IA13-03/USR13-01 — P1, подтверждено; `revise`.** API отсутствует: основной запрошенный сценарий получения данных через API недоступен. Снижение критиком до P2 опирается на работоспособность локального инкремента; оно не учитывает исходную цель. Протокол не ограничивает «отказ основного сценария» уже реализованными сценариями. Это оценка незавершённой цели, а не объявление новой финансовой регрессии вопреки QA. Исполнитель: backend-data; архитектура подтверждает provider contract. Закрытие: фактический QR, доказанный доступ/success-schema, реализация API и независимый QA успешного ответа и ошибок. Если зависимость недоступна, цель остаётся открытой.

2. **BANK14-01/QA14-01/CR14-01/IA14-01/USR14-01 — P2, наблюдение подтверждено, причина неизвестна; `insufficient_evidence`.** Доступ и выбор Freedom/Halyk подтверждены пользователем. Новое дополнение фиксирует SM-S921B/API36, установленную code2, активную службу/user0, requested/received/hasBound=true и наличие обоих пакетов. Старые ответы сторон о неизвестном binding этим уточнены. Однако callback, exact сохранённые sources/profile и payload не проверены; текст/extras/DB не читались. «0 инфы» не различает отсутствие события и пустые поля. Generic assembler не доказал исправление; отсутствие Kaspi OS-event здесь неприменимо. Исполнитель: backend-data в APP-015; закрытие — установить этап сбоя и независимо проверить новые события обоих банков на проверяемой версии в разрешённом объёме.

3. **IS13-01/ARCH13I-01/BD13-03/QA13-01/CR13-02/IA13-01/USR13-03 — P2, подтверждено; `revise`.** Повреждённый сосед может остаться необнаруженным, и будет выбран читаемый QR. [Исходный diagnostic test](../../android-app/app/src/test/java/com/ladno/finance/ReceiptQrDecoderTest.java) сохранён под `@Ignore`: это skip, не PASS и не исправление. Нарушение LC3 о нескольких decoded QR не доказано; review/noauto ограничивают последствия, неверная проводка не установлена. Исполнитель: backend-data, decoder. Закрытие дефекта: стратегия обработки этой неоднозначности и независимый повтор исходной фикстуры без skip; до этого ограничение сохраняется.

4. **C8-01/USR8-01/QA13-02/CR13-03/IA13-02/USR13-02 — P2, недостаточно данных; `insufficient_evidence`.** Реальный чек, видимый camera/gallery workflow и обновление пользовательской БД не испытаны. Совместимая подпись этого не доказывает; 0.3.0 на физическом телефоне ещё нет. Исполнитель: QA с владельцами UI/runtime при обнаружении дефекта. Закрытие: отдельная проверка видимого результата реального чека и обновления с сохранением данных/ignore на той же версии.

**Общий вердикт: `revise`.** Исходная обязательная цель не выполнена; открытый P1 блокирует общую приёмку. Причины банковского наблюдения и физический workflow остаются вопросами, не установленными дефектами новой версии.

**Отдельное решение: `approve` ограниченной экспериментальной передачи точного APK.** Допустимо представить локальное QR-предзаполнение и generic fields с обязательной ручной проверкой, явно раскрывая отсутствие API, неподтверждённое исправление Freedom/Halyk, повреждённый соседний QR и непроверенный физический workflow/обновление. Это не полная готовность и не разрешение суда на установку или публикацию. Следующее действие: начальник сохраняет вердикт и возвращает незакрытые пункты указанным исполнителям; повторный суд проверяет исправления и затронутые зависимости.

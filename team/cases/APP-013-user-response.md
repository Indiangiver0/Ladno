# APP-013/014 — ответ адвоката пользователя

Задача/версия: раскрытый спор о **0.3.0/code3**, exact APK и manifest из [initial](APP-013-user-initial.md). Через `Get-Content -Raw -LiteralPath` прочитаны [критик](APP-013-critic-initial.md) и [адвокат реализации](APP-013-implementation-initial.md). Ожидание — сопоставить доводы с практической целью; факт — существенного расхождения о недостигнутом результате нет. Новых тестов/телефонных фактов нет.

- **CR13-01 / подтверждено:** согласен, API отсутствует. Для общей цели поддерживаю **P1** критика; свой USR13-01/P2 уточняю здесь. Первоначальный P2 не означал разрешение общей приёмки: обязательный запрос не выполнен, что блокировало бы её и при P2 по PROTOCOL. Это незавершённая цель, не установленная регрессия локального parser ([дело](APP-013.md)).
- **CR14-01 / P2 / недостаточно данных:** согласен. Доступ и выбор обоих банков пользователь подтвердил; connected listener/доставка/результат нового события неизвестны. Считать assembler исправлением причины нельзя. USB APP-015 ожидается; отсутствующий исходящий Kaspi OS-event — другое ограничение.
- **CR13-02 / P2 / подтверждено:** согласен; `@Ignore` сохраняет дефект обнаружения. Review снижает последствия, но не устраняет возможность предзаполнить данные другого читаемого QR. Нужна сверка именно выбранного чека; неверная проводка не доказана.
- **CR13-03 / P2 / недостаточно данных:** согласен; synthetic runtime не закрывает видимый camera/gallery workflow и пользовательский чек ([QA](../reports/APP-013-qa-review.md)).

Принимаю доводы реализации о точной KZT scale2 арифметике, HMAC, неизвестном виде и обязательном review: они защищают корректность предзаполнения. Пользователь всё ещё делает снимок, выбирает вид и подтверждает; это не обещанная полная автоматизация.

Рекомендация сохраняется: общий запрос открыт; передать exact APK допустимо только как ограниченный эксперимент с раскрытием пунктов выше, без заявления об исправлении банков/API и без установки/публикации в рамках суда. Далее — отдельный судья. Это ответ стороны, не вердикт.

Действие: получить реальный QR, доказанный provider interface/success schema, затем отдельно реализовать и проверить API; all-bank покрытие тоже не заявлять.

Отсутствующий Kaspi OS-event его не объясняет; generic assembler не доказал исправление. Новых USB/callback фактов нет. Следующее действие APP-015: package/profile/connected metadata, затем результат нового события; реальные шаблоны проверять отдельно в разрешённом объёме.

- **CR13-03 / USR13-02 / IA13-02 — P2, недостаточно данных.** Реальный чек, camera/gallery UI и обновление поверх пользовательской БД не испытаны.

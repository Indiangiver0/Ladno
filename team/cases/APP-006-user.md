# APP-006 — независимая первоначальная позиция адвоката пользователя

Задача: адресно оценить новые доказательства по исходным A2–A5 и USR-01–03; обязательные автопост и последующая категория сохраняются. Автором production/tests/evidence не являюсь, новые позиции других сторон не читал и выводы не согласовывал.
Версия `android-alpha-v2`, 215 файлов, digest `b92d7a8f600e73720c415ad18579aaf70ec2166e1ca4a3009314cce1aec6bc16`; неизменный main APK SHA `38c9d4490419eda3685e7187281d5f1ecfb958a95d77c57f7f59633febcfbd5a`.

## Выполненное и доказательства

Прочитаны [дело](APP-006.md), [новый QA-head](../reports/APP-006-qa-review.md), оба Android QA REPORT и прежний вердикт. Собственная read-only команда: PowerShell here-string→Python `json/pathlib/hashlib`, bytes/SHA всех snapshot.files, canonical `sha256 + two spaces + path + LF`, отдельно APK. Ожидание: 215 совпадений/заданные digest/APK; факт exit0, `mismatches=[]`, оба SHA совпали. Продукт не менял, Android-тесты не повторял.
По [N1](../../android-app/qa/android-calculation/REPORT.md) и [N2/N3](../../android-app/qa/android-scenario/REPORT.md), отдельно проверенным главой: 388 runtime assertions PASS в шести успешных instrumentation-командах на AOSP Android11/API30 x86_64. Root исполнил команды, независимые QA задали ожидания/разобрали факты; выполнение себе не присваиваю. Три прежних FAIL сохранены и не превращены в PASS; production-отказ по ним не установлен.

## Изменение оценки и замечания

- **USR-01 / P2 / частично закрыт новыми доказательствами; оставшийся пробел подтверждён, отказ продукта не установлен.** A2 теперь имеет настоящее native CRUD/categories/SQLite и сохранение ID/правок после force-stop в новом процессе. A5 существенно подтверждён native exact aggregate/CAS/replay/tombstones/post/link/ignore и сохранением итогов; прежние формулировки «постоянство/агрегатор не исполнялись» устарели. Не требую повторять эти PASS без причины.
- В A3 настоящий OS NLS после наблюдаемой готовности автоматически внёс доход/расход без категории; AndroidKeyStore и ограниченный revoke/no-capture проверены. В A4 настоящий Tesseract→NativeRuntime→SQLite автоматически внёс paid EN/RU 123.45/234.56 KZT, unpaid остались вне итогов; image replay/invalid-image безопасны. Это значимый результат по пользовательской цели, а не только наличие кода.
- **USR-01, остаток / P2:** ещё не исполнены пользовательские MainActivity/WebView→форма→AppBridge, выбор источника и штатный путь системного разрешения/первой доставки, камера/галерея→URI→зарегистрированный job→показ результата. Test-only unregistered jobId доказывает data path, но не сканирование через приложение. Нужно проверить эти оставшиеся сквозные пути и отображаемые суммы/статусы/сохранение правки на той же версии; API30/native PASS не заменяет их. Источник: QA-head A2–A5 и scenario «Невыполненные проверки».
- **USR-02 / P2 / открыт: ограничение охвата подтверждено.** N4 честно описывает synthetic own-package/generic EN/RU/KZT, а не проверенные реальные банки. Охват «все банки» не достигнут доказательствами; цели не отменять и неподтверждённую несовместимость не выдумывать. Native UI собственный test-package исключает: это не испытание выбора банка пользователем.
- **Связанный IA005-03 / P2 / практическое ограничение OCR подтверждено, масштаб неизвестен.** В KZ paid CanvasPNG OCR исказил «Төленген»; результат review безопасен для денег, но не является успешным автоматическим внесением оплаченного KZ-чека. Из шести изображений posted ровно два EN/RU, а не шесть. Реальные кассовые фото/языковое покрытие требуют размеченных входов; не предлагаю ослаблять защиту от неоплаченного чека ради формального автопоста.
- **USR-03 / P2 / актуальное условие передачи:** прежнюю оговорку «не устанавливали и не запускали на Android» использовать нельзя. Теперь есть установка и настоящее native-исполнение; недостаточно испытан именно полный пользовательский путь. Достаточен ясный handoff ниже рядом с APK/[README](../../android-app/README.md), без изменения frozen215; закрытие коммуникационного пункта — по фактически отправленному тексту.

> Собран debug APK «Ладно» 0.1.0 для личной установки на Android 8+. Это альфа: на эмуляторе Android 11 проверены сохранение записей, точные итоги, автоматический ввод синтетических уведомлений и распознавание тестовых чеков. Экраны самого Android-приложения, камера/галерея, реальные банковские уведомления и фото чеков ещё не проверены; все банки и точность распознавания всех языков не подтверждены. На двух телефонах отдельные базы без синхронизации. Экспорта и восстановления нет: при удалении приложения или потере телефона записи могут быть утрачены. Полная приёмка ещё не выполнена.

## Следующее действие и вопросы

Рекомендую `insufficient_evidence` по полной задаче из-за оставшихся обязательных пользовательских путей/охвата, с признанием закрытой native-части USR-01. Передача неизменного APK как альфы допустима с обновлённым handoff; это не замена полной цели промежуточным результатом. Не делаю sync/export обязательными функциями, но риск единственной копии должен быть сообщён. Дальше — адресный UI/media/permission проход и реальные обезличенные форматы с ожидаемыми результатами; целевой телефон/корпус остаются открыты. Подтверждённых новых P0/P1 не заявляю. После раскрытия отвечу сторонам; отдельный судья оценит достаточность доказательств.

# APP-013/014 — ответ критика после раскрытия

Версия прежняя: 0.3.0/code3, APK SHA256 `a8ec70cd97674fb6f9c8d224e10139611c52a4ac25f69f6cd26143f7d88e5b76`. Прочитаны [защита реализации](APP-013-implementation-initial.md) и [позиция пользователя](APP-013-user-initial.md). Новые тесты/телефонные действия не выполнялись; новых фактов APP-015 нет.

- **CR13-01 → P2 / подтверждённая неполнота обязательного требования.** Принимаю оценку IA13-03/USR13-01. Первоначальная P1 избыточна относительно шкалы протокола: отсутствие API подтверждено, однако воспроизводимый неверный финансовый результат либо отказ реализованного основного сценария этого APK не установлен. По [QA](../reports/APP-013-qa-review.md) локальный сценарий работает в проверенных границах. Обязательный P2 всё равно блокирует признание общего запроса выполненным. Нужны QR/provider/success-schema, реализация и проверка API; формальное предзаполнение этого не заменяет.
- **CR14-01 / P2 / недостаточно данных:** согласен с IA14-01/USR14-01. Доступ и выбор обоих банков пользователь подтвердил; повторно считать их неизвестными нельзя. Не установлены точные package/profile, connected-состояние и судьба нового события. [APP-015](../reports/APP-015-capture-triage.md) не доказывает ни причину, ни исправление; отсутствие OS-события Kaspi здесь неприменимо.
- **CR13-02 / P2 / подтверждённое ограничение:** IA13-01/USR13-03 его признают. Защита review/noauto обоснованно ограничивает последствия; обвинения в неверной проводке нет. `@Ignore` не исправление и не PASS, но нарушения LC3 о decoded QR не доказано.
- **CR13-03 / P2 / недостаточно данных:** согласен с IA13-02/USR13-02. Reflection/native assertions не закрывают камеру/галерею; совместимая подпись не доказывает обновление пользовательской БД.

Принимаю защиту полезности строгого локального prefill: exact KZT scale2, неизвестный вид/review, отсутствие autoledger и сохранение ignore подтверждены ограниченными проверками. Поддерживаю передачу точного APK как эксперимента с раскрытием ограничений; общую готовность и восстановление Freedom/Halyk не подтверждаю. Финальное решение остаётся судье.

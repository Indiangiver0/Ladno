Выполнено: `Get-Content` трёх initial [критика](APP-005-critic.md), [адвоката реализации](APP-005-implementation.md), [адвоката пользователя](APP-005-user.md). ## Ответы на защиту и замечания

- **CR005-01 → IA005-01, USR-01 / P2 / признаю.** Оба адвоката подтверждают C005-01, не опровергают его. [QA A2–A5](../reports/APP-005-qa-review.md) остаются частичными. Это доказанный пробел исполнения, а не доказанная потеря данных/неверный расчёт; P1 не назначаю. C005-01 остаётся открытым для полной приёмки.
- **CR005-02 → IA005-02, USR-02 / P2 / признаю предел доказательств.** Поддержка «всех банков» не установлена. Наличие parser/NLS и выбранных источников не является матрицей реального покрытия. Сохраняю U5 открытой целью; не делаю вывода, что все банки обязательно не работают. Для закрытия нужны размеченные обезличенные форматы и Android-доставка с проверенной областью покрытия, а не передача личных сообщений как условие получения APK.
- **CR005-03 → IA005-03 / P2 / уточняю статус.** Требование явного paid marker установлено кодом и подтверждено regression QA-CALC01. Оно сознательно предотвращает ложный расход. Существование и доля оплаченных чеков, которые это правило отклонит в целевом корпусе, данным делом не измерены: это ограничение применимости/гипотеза о масштабе, не воспроизведённый отказ R4. Нужен размеченный RU/KZ/EN корпус через настоящий media→OCR→parser; ослабление guard без negative regressions не обосновано.
- **CR005-04 → USR-03 / P2 / согласен с устранением при передаче.** Слова README «OCR работает на телефоне» и отсутствие там прямого списка невыполненных запусков — проверяемый текстовый факт; более сильное впечатление конкретного пользователя не наблюдалось. Явная финальная оговорка рядом со ссылкой на APK/руководство устраняет неоднозначность передачи без правки замороженных 108 файлов. Сейчас это ещё требуемое действие, не уже выполненное закрытие. Оговорка не закрывает USR-01/02 или C005-01.

## Условие передачи и следующий шаг

Допустимая передача: назвать результат экспериментальным debug APK для личной установки и следующей проверки; прямо указать, что установка/запуск Android, native persistence, камера/OCR и NLS end-to-end не исполнялись, «все банки» не подтверждены; сообщить об отсутствии экспорта/восстановления и отдельных базах телефонов. Не обещать проверенную работоспособность, не объявлять исходный запрос полностью выполненным. Отдельного согласования публикации такая передача не заменяет.

Для полной приёмки остаются Android fresh install/setup/CRUD/categories/restart; положительные/сомнительные OCR и уведомления; точные суммы/валюты/даты; replay/revoke, edit/delete/replay, receipt+notification и post/link/ignore с проверкой итогов и сохранения правок. Выполнение и ожидания должны быть зафиксированы по рассматриваемому APK; исправления при найденном отказе возвращаются владельцам с повтором затронутых проверок.

Рекомендация по полной готовности сохраняется: **insufficient_evidence**. Возражений против ограниченной передачи при указанном сообщении нет; новых доказанных продуктовых P0/P1 не предъявляю. Судья определяет итог и его область, не обязан разрешать несуществующее разногласие сторон.

Существенные замечания:

- **C005-01→C006-01 / IA005-01 / USR-01, P2:** подтверждённое частичное закрытие native-пробела; остаток — пробел доказательств, не установленный отказ продукта. Решение `insufficient_evidence` для оставшихся UI/media/permission путей. Причина: API-проход обходит обязательные пользовательские переходы. Исполнитель: независимый scenario QA; qa-lead проверяет Android UI→bridge, source picker/grant/первую доставку, camera/gallery→штатный job→запись/отображение, persistence и сохранение правок. Уже PASS native-набор без новой причины не повторять.
- **C006-02 / IA005-02 / USR-02, P2:** подтверждённая граница покрытия; решение `insufficient_evidence`. Настоящая доставка синтетического сообщения не доказывает конкретный банк. Исполнители: product-/backend-lead и независимый QA; закрытие — обезличенные реальные templates/app versions/channel + expected/actual parser/delivery, отдельная проверка product-/qa-lead. «Все банки» остаётся открытой целью; сокращать её без явного решения пользователя нельзя.
- **C006-03 / IA005-03, P2:** подтверждён ограниченный false negative KZpaid: «Төленген»→«Теленген», mean93, UNSUPPORTED_EVENT/review. Решение `insufficient_evidence` практической KZ-autoaccuracy; безопасный review принимается, успешный автопост этого образца не заявляется. Ошибочный денежный итог/массовый отказ/P1 не доказаны. Исполнители: backend-lead и независимый QA; следующий шаг — размеченный целевой корпус/искажения, отрицательные unpaid-регрессии, проверка главой. Суд не задаёт процент качества и не требует ослабить finality ради формального PASS.
- **USR-03, P2 — `revise`:** старое «Android не устанавливали/не запускали» теперь неверно для native API области. Chief закрывает коммуникационный пункт фактически отправленным сообщением ниже рядом с APK/README; повторная проверка — сохранённый текст финала. Frozen215/README менять для этого не требуется; прочие пробелы оговоркой не закрываются.
- CR006-01/02/03/04 — ответы по тем же группам соответственно C006-01/02/03 и USR-03; все их существенные доводы рассмотрены выше.

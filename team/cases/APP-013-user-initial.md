## Замечания

- **USR13-01 / P2 / подтверждено:** API не подключён; два локальных формата дают лишь сумму/дату. Пользователь ещё выбирает вид и подтверждает запись. Это полезное предзаполнение, но обязательная общая цель API/меньше ручного учёта не закрыта ([дело](APP-013.md), [контракт](../../docs/android/APP-013-QR-CONTRACT.md)).
- **USR14-01 / P2 / причина не установлена:** пользователь видит Freedom/Halyk в Android при включённом доступе и выбранных банках, но приложение 0.2.0 ничего не показывает. Исправление в 0.3.0 не доказано; нельзя объяснять это отсутствующим OS-событием Kaspi или обещать автоматический захват ([дело](APP-013.md)).
- **USR13-02 / P2 / недостаточно доказательств:** пользовательский QR, camera/gallery UI и обновление поверх пользовательской БД не испытаны. Практическая работоспособность на его телефоне остаётся открытой ([QA](../reports/APP-013-qa-review.md)).
- **USR13-03 / P2 / подтверждено, QA13-01:** повреждённый соседний QR может остаться незамеченным; `@Ignore` не исправление. Нужна ручная сверка выбранного чека; автоматическая неверная проводка не установлена ([тест](../../android-app/app/src/test/java/com/ladno/finance/ReceiptQrDecoderTest.java)).

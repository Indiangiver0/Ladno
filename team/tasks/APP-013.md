# APP-013: QR бумажного чека и получение его данных

- Запрос: после тестов пользователь просит подключить API, чтобы сканировать QR чеков и получать данные для учёта расходов.
- Статус: needs_information для исходной API-цели; отдельный локальный инкремент передан как ограниченный эксперимент, не полная приёмка.
- Ответственный отдел: architecture (контракт источников), затем backend-data и frontend для реализации после подтверждения контракта.
- Глава архитектуры: реальный `/root/kaspi_compat_arch_lead`; специалисты назначаются им реальными вызовами. Root координирует зависимости.
- Контекст: Android/KZ/Kaspi, текущая alpha 0.2.0; офлайн OCR не декодирует QR. Исходящие операции без системного уведомления являются отдельной проблемой APP-014.
- Критерии: декодировать QR из уже поддержанных камера/галерея изображений; извлекать только подтверждённые поля с точными денежными значениями (KZT, 2 десятичных разряда, без округления лишних дробей); не принимать платёжный QR за фискальный чек; дубликаты/ошибки видимы; не обещать поддержку всех OFD/API без доказательств. Внешнее получение — по подтверждённому официальному интерфейсу, без секретов в APK и произвольной загрузки URL. Финансовая запись не должна ошибочно менять направление по одному QR без типа операции.
- Открытые вопросы: фактический QR пользователя и формат; документированный потребительский API KZ, доступ/ключи/условия. Эти сведения не выдумываются. Запрос разрешает проработку receipt API, но не расширяет APP-010 consent на банковские экраны.
- Владение на исследовательском этапе: system-architect — `docs/android/APP-013-QR-CONTRACT.md`; security-engineer — `docs/android/APP-013-QR-SECURITY.md`; глава — `team/reports/APP-013-architecture-review.md`. Root — эта карточка, новые coordination/snapshot артефакты. Исходники пока никому не переданы.
- История: frozen v3/402 файла сначала архивируются по точным SHA, затем новая разработка может менять рабочие источники; старые snapshots/вердикты не переписываются. Старая версия остаётся отдельно доступна.
- Проверка главы, независимый QA и четыре роли суда: ещё не выполнялись для новой реализации. Готовность не объявляется по одному исследованию.

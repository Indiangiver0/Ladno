- Артефакт остаётся основным android-app/dist/ladno-0.2.0-debug.apk, SHA f73e04a0202418ee1dc59c1e669a57228988607de9fb1f60bd388b8e4a20beac, 68092906B, com.ladno.finance/code2/name0.2.0. Не новый reader/не androidTest.
- Root выполняет техническую диспетчеризацию доставки; проверяющий ответственный отдел architecture/security, ранее выполненная схема APP-011. После появления цели возвращается реальный tester_install_review_lead для отдельной проверки нового свидетельства. Глава сейчас не запущен для ожидания отсутствующего устройства.
- Пользователю запрошены физическое подключение/разблокирование/USB-debugging и ручное RSA подтверждение при появлении. Это не повторное формальное разрешение установки; root не включает OS разрешения сам.
- После появления единственного нового авторизованного телефона: явный target, metadata/API/current package version и SHA проверки, install-r --no-incremental без clear/uninstall/grants/UI/чтения финансовых данных, readback code2/name0.2.0. При нескольких/неоднозначных телефонах уточнить цель, не выбирать случайно.
- Новые delivery/report файлы вне402frozenфайлов; главный APK/старые вердикты не меняются. Установка не подтверждает банковский/camera end-to-end или zero-touch Kaspi.

## Обновление после подключения

- Пользователь ответил «Подключил, отладка включена». Обнаружена единственная авторизованная новая модель V2443BA/API35; пакет перед установкой отсутствовал. Полный serial намеренно не сохраняется в репозитории; все реальные команды использовали одну явную цель.
- Реальный глава повторно активирован: `/root/tester_install_review_lead`; реальный специалист `/root/tester_install_review_lead/security_delivery_verify`. Ответственный отдел architecture/security. Root владеет этой карточкой и `team/reports/APP-012-delivery.md`; глава владеет только новым `team/reports/APP-012-delivery-review.md`.
- Первая streamed install завершилась exit1/INSTALL_FAILED_ABORTED/User rejected permissions; пользователь не видел окна. Обычная повторная push install (`-r --no-streaming --no-incremental`) того же APK завершилась exit0/Success. Затем независимо от install-вывода прочитаны code2 и name0.2.0 с выбранного телефона. Очистка, uninstall и выдача разрешений не выполнялись.
- Критерии доставки: неизменный основной APK, однозначная авторизованная цель, совместимый Android, успешная установка и совпадение readback package/version. Все фактические результаты сохранены в APP-012-delivery.md; проверка главы/специалиста отдельная. Полную продуктовую приёмку и прежний verdict эта доставка не заменяет.

# APP-014: меньше ручного ввода банковских операций

- Запрос: приложение получает ограниченную информацию, многие переводы и пополнения заполняются вручную.
- Статус: needs_information для полноты реального банковского учёта; genericпредзаполнение реализовано/испытано и передано ограниченным экспериментом, конкретные Freedom/Halyk ещё не подтверждены.
- Ответственный отдел: backend-data, реальный глава `/root/import_backend_lead`. Отдельная смежная задача APP-013 отвечает за QR чеков.
- Подтверждённый предел: если исходящего уведомления нет в Android, NotificationListener его не получает. Новый запрос не расширяет узкий APP-010 consent на банковские экраны; accessibility/логин в банк не назначаются.
- Критерии: расширить извлечение направления/суммы/даты из доступного сообщения с безопасными точными правилами, поддержать подтверждённые форматы уведомлений; баланс/комиссия/отмена/между своими счетами не становятся ложными доходами/расходами; минимизировать ручной ввод без выдуманных данных. Не обещать универсальное подключение всех банков.
- План: глава выдаёт две отдельные подзадачи backend-engineer/data-engineer, назначает ownership после архивирования старой версии; проверяет их результаты отдельно. Пока владеет только `team/reports/APP-014-backend-plan.md`. Исходники на этом этапе не изменяются.
- Версия: основание 0.2.0/code2, SHA f73e04a0202418ee1dc59c1e669a57228988607de9fb1f60bd388b8e4a20beac; не новая проверенная версия. Новые QA/суд ещё не выполнены.

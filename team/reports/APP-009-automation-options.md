## Подтверждённые границы

- Пользователь отверг пересылку чека после каждого мелкого перевода. Отсутствие исходящего уведомления подтверждено им отдельно для системной шторки, а не только всплывающего окна. При таком наблюдении текущий NotificationListener не получает событие перевода.
- Kaspi документирует выписку со всеми видами операций Kaspi Gold, выбор периода и отправку PDF. Это подтверждает источник одного файла для множества операций, но не автоматическую доставку или API. [Официальная инструкция, обновлена 04.06.2026](https://guide.kaspi.kz/client/ru/bank/information_statement/gold/q976).
- В 0.2.0 нет приёма PDF/share; gallery ограничена image/*. Source kind для импорта сейчас notification|receipt; у приложения нет INTERNET или Accessibility service. Пакетный импорт требует новой реализации, а не переключателя готовой функции.

## Рекомендуемый вариант при допустимом периодическом действии

Одной выпиской за выбранный период загружать сразу множество операций. Например, пользователь передаёт PDF раз в неделю; адаптер разбирает строки, показывает пакет и сохраняет согласованные записи. После каждого перевода действий нет, но это периодический ручной импорт и задержка учёта, а не полная фоновая синхронизация. Этот вариант пока только предложение, пользователь его не выбрал.

Минимальные условия реализации: отдельный локальный source adapter и согласованный statement provenance/source kind с миграцией; строки сумм/точные минимальные единицы по MONEY, даты самих операций, разделение валют и периода; балансы/итоги/дата экспорта не становятся операциями. Правила направлений, переводов себе, возвратов и комиссий нельзя угадать из знака строки без разбора формата и согласования.

Exact replay одного документа должен быть идемпотентен по scoped HMAC. Для пересекающихся выписок и уже учтённых уведомлений нужен устойчивый банковский ID, если он присутствует. Равные дата/сумма не доказывают одну операцию: возможные совпадения требуют отдельного решения, нельзя автоматически сливать разные одинаковые переводы или удваивать приход. Формат и библиотеку PDF-извлечения выбрать после образца.

## Если требуется строго ноль регулярных действий

Текущему приложению необходим новый автоматически поступающий источник: например, поддерживаемая банковская синхронизация или автоматически доставляемые данные. Доступность подходящего личного API Kaspi этой оценкой не установлена; отсутствие найденного API не является доказательством его несуществования. Чтение экрана/приватной БД банка, автоматизация банковского UI и получение credentials не назначены и не проверены, поэтому не представляются готовым решением.

Следующий вход зависит от выбора: для batch — один настоящий PDF за небольшой период, при желании с обезличенными ФИО/счётом, но сохранёнными структурой, датами, знаками, валютой и строками операций. Это одноразовый образец для разработки, а не чек каждого перевода. Если неприемлемо даже недельное действие, нужен отдельный поиск и подтверждение разрешённого автоматического источника.

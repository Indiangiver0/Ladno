- Native client формирует только fixed HTTPS GET `consumer.oofd.kz/api/consumer-proxy/api/tickets/get-by-url` из strict validated i/f/s/t. Platform DNS может не реагировать на interrupt, но число worker/queue ограничено. Caller/transport исключения не передают raw URL/body в UI/logs. Это source плюс synthetic transport проверки, не фактический Android HTTP time benchmark.
- OfdJson сохраняет исходные NumberToken lexemes, ограничивает depth16/array500/body/string/object/number, отвергает duplicate keys и плохие Unicode strings. Refund/op0/1/3/unknown/cancel/offline/mismatch и непроверенная схема не становятся обычным автоматическим расходом.

**DEL18-01 / открыто:** отсутствует фактическое свидетельство установки и readback. На старте root сообщил пустой `adb devices -l`. Пассивный следующий шаг root — метаданные присутствующих Windows USB/Android устройств (class/friendlyname/status без публикации serial), чтобы отделить отсутствие USB transport от ADB-интерфейса/авторизации. Если телефон появится: одна явная подтверждённая цель, `install -r --no-incremental` только main APK, затем отдельный readback code4/name0.4.0. До этого установка не подтверждена.

После первоначальной проверки root передал безопасную сводку собственных команд: Windows PresentOnly показывает OK Samsung composite/modem/Android ADB Interface; adb server-status указывает ожидаемый SDK37.0.1/cache path, backend NATIVE и прежний default key path. До и после одного `kill-server` → `start-server` (exit0) devices-l пуст. Root не менял device/security/key/driver configuration и не пытался install/readback. Пользователю предложены разблокировка, переключение USB-debug и подтверждение RSA. Это факты по сообщению root, а не самостоятельно выполненные главой аппаратные проверки; установка остаётся неподтверждённой. Дальнейший review возобновляется при фактической delivery записи.

Общие verdict/QA не переписываются; операционная передача не закрывает DEC-01/P1 и не доказывает физическую камеру, банковские callback или сохранность каждой денежной записи.
